# Specification: E-Cards Platform Complete Redesign & Enhancement
## منظومة بطاقات الامتنان والتهاني - إعادة التصميم الشاملة وهوية عبد اللطيف جميل للتمويل

**التاريخ:** 2026-09-20  
**الحالة:** معتمد للمراجعة (Approved for Spec Review)  
**المشروع:** منصة بطاقات الامتنان والتهاني (Gratitude E-Cards Platform)  

---

## 1. ملخص المشروع وأهدافه (Executive Summary)
تهدف هذه المواصفة إلى إعادة تصميم منصة بطاقات الامتنان والتهاني داخلياً بالكامل لتلبي أعلى المعايير الاحترافية، وتطبيق الهوية البصرية الرسمية لشركة عبد اللطيف جميل للتمويل (ALJ Finance)، مع إتاحة مرونة مطلقة للمشرف (Admin) في تخصيص القوالب وتحديد مواضع النصوص وعددها وحجمها ولونها بشكل مرئي وسلس، ودعم قوالب ثنائية اللغة (عربي / إنجليزي) لكل مناسبة، وتوفير شاشة تحليلات وتقارير متطورة لمتابعة إصدارات البطاقات وتصديرها.

## 2. الهوية البصرية ونظام التصميم (ALJUF Visual Identity)
الالتزام الصارم بمواصفات وأصول هوية عبد اللطيف جميل للتمويل:
- **الشعارات الرسمية:**
  - استيراد واستخدام شعارات الجوف المعتمدة الرسمية (`ALJUF_Logo-01` للنسخة العربية الملونة، `ALJUF_Logo-03` للنسخة الإنجليزية، ونسخ الأبيض الشفاف `ALJUF_Logo-02` و `04` للخلفيات الداكنة).
  - تثبيت الشعار في الترويسة العليا للمنصة وصفحة تسجيل الدخول ولوحة الإدارة وتذييل الصفحات.
- **لوحة الألوان الأساسية:**
  - البنفسجي الأساسي (`--color-primary`): `#3C1053`
  - البنفسجي الداكن (`--color-primary-dark`): `#2B0A3D` / `#32134C`
  - الذهبي التمييزي (`--color-accent`): `#FFCD00` / `#FFCB28` (للأزرار الرئيسية، الشارات المميزة، والتبويبات النشطة)
  - الرمادي المؤسسي (`--color-gray`): `#63656A` / `#5C6670`
  - الأزرق الهادئ (`--color-blue`): `#47859F`
  - ألوان الأسطح: الداكن الفخم (`#0A0A0C`، `#121215`، `#18181D`) مع دعم التباين الفاتح.
- **الطباعة والخطوط (Typography):**
  - اعتماد خطوط `Luma` (SemiBold / Regular) للعربية مع البديل `Tajawal`.
  - اعتماد خطوط `Karbon` (Bold / Regular) للإنجليزية مع البديل `Instrument Sans` / `Arial`.

## 3. المعمارية ونموذج البيانات (Architecture & Database Schema)

### 3.1 ترحيلات قاعدة البيانات (SQLite Schema Migrations)
إنشاء الترحيل `000002_dynamic_templates.up.sql` مع الحفاظ على وضعية `WAL` لسرعة القراءة والكتابة:
- جدول المناسبات (`campaigns`):
  - إضافة عمود `template_ar` (نوع `TEXT / JSON`): يحفظ إعدادات القالب العربي:
    - `image`: صورة القالب عالية الدقة (Base64 أو المسار).
    - `fields`: مصفوفة حقول النصوص `TextFieldConfig[]`.
  - إضافة عمود `template_en` (نوع `TEXT / JSON`): يحفظ إعدادات القالب الإنجليزي:
    - `image`: صورة القالب عالية الدقة.
    - `fields`: مصفوفة حقول النصوص `TextFieldConfig[]`.
  - الاحتفاظ بالحقول المشتركة: `id`, `slug`, `title`, `active`, `created_at`.
- جدول سجل البطاقات (`campaign_cards`):
  - إضافة عمود `lang` (`TEXT`): يحدد لغة البطاقة المختارة (`ar` أو `en`).
  - إضافة عمود `field_values` (`TEXT / JSON`): يخزن جميع القيم المدخلة بصيغة مرنة `{"name": "...", "title": "..."}`.
  - الاحتفاظ بأعمدة الفهرسة والبحث: `campaign_slug`, `date_str`, `time_str`, `created_at`.

### 3.2 هيكل الحقل النصي الديناميكي (TextFieldConfig)
```typescript
export interface TextFieldConfig {
  id: string;          // معرف فريد للحقل مثل: 'emp_name', 'job_title'
  name: string;        // التسمية التقنية
  label: string;       // التسمية الظاهرة للمستخدم (مثل: اسم الزميل)
  placeholder: string; // نص تلميح للإدخال
  x: number;           // إحداثي X على الكانفاس (أبعاد 1080x1350)
  y: number;           // إحداثي Y على الكانفاس
  width: number;       // عرض المربع
  height: number;      // ارتفاع المربع
  fontSize: number;    // حجم الخط (افتراضي 40)
  color: string;       // لون الخط (مثل #FFFFFF أو #FFCD00)
  weight: 'bold' | 'regular';
  align: 'center' | 'right' | 'left';
  maxChars?: number;   // الحد الأقصى للأحرف
  required?: boolean;  // هل الإدخال إلزامي
  order: number;       // ترتيب الحقل في النموذج
}

export interface TemplateVariant {
  image: string;       // Base64 أو رابط صورة الكانفاس
  fields: TextFieldConfig[];
}
```

## 4. موديول تخصيص القوالب للمشرف (Visual Template & Position Builder)
توفير شاشة تفاعلية ذكية داخل لوحة الإدارة تمكّن المشرف من التعديل الشامل:
1. **التبديل بين اللغتين (Tabs):**
   - تبويب القالب العربي: رفع صورة العيد/المناسبة بالعربية وتحديد حقولها النصية ومواقعها.
   - تبويب القالب الإنجليزي: رفع الصورة الإنجليزية وتحديد حقولها النصية الخاصة ومواقعها.
2. **المعاينة المزدوجة التفاعلية (Dual Canvas Layout):**
   - **الجانب الأيسر (Interactive Canvas):**
     - تمثيل تفاعلي لبطاقة العيد مع إمكانية تحريك المستطيل (`Draggable Box`) وتغيير حجمه (`Resizable Handles`) مباشرة بالماوس أو اللمس.
     - تحديد الموقع والأبعاد بدقة البكسل (`x`, `y`, `width`, `height`).
   - **الجانب الأيمن (Live Preview):**
     - معاينة فورية تظهر كيف ستبدو البطاقة للموظف بالخطوط الرسمية والألوان الحقيقية أثناء التعديل.
3. **التحكم الكامل بالحقول (Field Management):**
   - إضافة حقل جديد (زر `➕ إضافة حقل نصي`).
   - حذف أي حقل موجود.
   - تحديد اسم الحقل والتسمية الظاهرة للموظف.
   - اختيار لون النص وحجم الخط ونوع الخط ومحاذاته.
   - تحديد التباعد والفجوة (`Gap`).
   - حفظ التعديلات بضغطة زر وتحديث المناسبة فورياً.

## 5. تجربة الموظف وتوليد البطاقة (Employee Generation Workflow)
1. **الرابط والوصول:**
   - الدخول المباشر عبر الروابط الآمنة `/cards/[slug]`.
2. **اختيار لغة البطاقة (Language Switcher):**
   - خيار بارز للموظف في رأس الصفحة للاختيار بين: **[ العربية ]** أو **[ English ]**.
   - تحميل القالب المناسب للغة فوراً مع تغيير الحقول وتلميحاتها واتجاه الواجهة (`RTL / LTR`).
3. **توليد الحقول ديناميكياً:**
   - توليد حقول الإدخال حسب ما ضبطه المشرف في ذلك القالب.
   - تحديث الكانفاس اللحظي فور إدخال أي حرف.
4. **التصدير الفوري:**
   - تنزيل البطاقة بدقة عالية PNG بنقاوة كاملة (1080x1350).
   - إرسال بيانات الإحصائيات في الخلفية لتسجيلها في لوحة التقارير دون تعطيل تجربة الموظف.

## 6. موديول النتائج والتقارير (Card Generating Analytics & Reports)
تصميم احترافي مطابق لمتطلبات الصورة المرفقة مع تطبيق استبعاد تفصيل الأجهزة:
1. **رأس الصفحة ومؤشر التحديث:**
   - العنوان: «إحصائيات توليد البطاقات | Card Generating Analytics».
   - وقت آخر تحديث مباشر: `Updated: HH:MM:SS`.
   - زر التحديث اليدوي `Refresh`.
   - زر التصدير `Export to Excel / CSV`.
2. **تبويبات المناسبات (Campaign Tabs):**
   - قائمة أفقية بكافة المناسبات النشطة مع خط سفلي ذهبي للتبويب النشط.
   - التبديل الفوري بين المناسبات لعرض إحصائيات كل مناسبة وجدول موظفيها دون إعادة تحميل الصفحة.
3. **بطاقة الإحصائيات العامة (All Time Stats):**
   - عرض إجمالي البطاقات المُصدرة (`Total Cards Generated`) برقم ذهبي ضخم وبطاقة فخمة.
   - عرض بطاقات اليوم (`Cards Today`).
   *(ملاحظة معتمدة: لا يتم عرض تفريغ iPhone / Android بناءً على التوجيه الصريح)*.
4. **جدول سجل الموظفين (Employee Cards List):**
   - شريط العنوان: «بطاقات الموظفين | Employee Cards» مع عداد البطاقات (مثل: `201 total`).
   - مربع بحث سريع للبحث في أسماء الموظفين والمسميات الوظيفية.
   - أعمدة الجدول:
     - الاسم الكامل (Full Name).
     - المسمى الوظيفي / البيانات الإضافية (Job Title / Details).
     - اللغة المختارة (Language: عربي / English).
     - التاريخ (Date).
     - الوقت (Time).

## 7. خطة الاختبار والتحقق (Verification & Testing)
1. التحقق من سلامة قاعدة البيانات وترحيل البيانات القديمة بسلاسة دون فقدان أي بيانات سابقة.
2. اختبار محرر المواضع التفاعلي بالسحب والإفلات وتغيير المقاسات وتأكيد حفظ الإحداثيات بدقة.
3. اختبار التبديل بين اللغتين (عربي / إنجليزي) في واجهة المشرف وواجهة الموظف.
4. اختبار محرك الكانفاس الجديد والتأكد من دعم الخطوط الرسمية وتصدير الصورة بصيغة PNG نظيفة وعالية الدقة.
5. اختبار شاشة التحليلات وجدول الموظفين وخاصية تصدير CSV.
